CRITICAL IMPLEMENTATION DETAILS

1. Phase is PER-ROW, PER-FRAME:
   - Not per-pixel, not global
   - One phase value per row and per frame
   - Makes it row-dependent, column-independent

2. Phase Extraction (Hilbert Transform):
   - Position signal is sinusoidal along WIDTH dimension
   - Hilbert transform converts to analytic signal
   - Phase extracted at center pixel (W//2) for stability
   - Converted to sin/cos to avoid phase wrapping

3. U-Net vs BS-Net Phase Split:
   - U-Net gets ALL non-center frames: (T-1, H)
   - BS-Net gets ONLY center frame: (H,)
   - This is intentional - center frame is special (denoising target)

4. Phase Injection at BS-Net Layers:
   - Layer 0: 3-channel input [image, sin, cos]
   - Layers ≥1: Re-inject via learned 1×1 convolutions
   - Replaces scalar multiplication (without phase)

5. Why Rotations are Disabled:
   - Phase is per-row (constant along columns)
   - 90° rotation would mix row/column dimensions
   - This would corrupt phase information
   - Flips are safe because they preserve row/column structure
